# Gate Proposal `E-036` — Dependency Pins in `requirements.txt` and `requirements-scanner.txt`

- **Ledger ID**: `E-036` (`WS-I1`)
- **Gate Triggered**: **G3** (*"Adding, upgrading, downgrading, or removing a dependency; changing the Starlette/FastAPI pins or the add-on base image"*)
- **Status**: `DEFERRED-APPROVAL` (awaiting `approved E-036`)

## 1. Rationale & Evidence
- `requirements.txt:1-12` and `requirements-scanner.txt:1-9` currently list unpinned package names (`fastapi`, `uvicorn`, `pydantic`, `pandas`, `numpy`, `yfinance`, `requests`, `lxml`, `beautifulsoup4`).
- `scanner_service/web/views.py:6` imports `from fastapi.templating import Jinja2Templates`, which requires `jinja2` at runtime, but `jinja2` is omitted from `requirements-scanner.txt` (and `pip install fastapi` without `[standard]` does not install `jinja2`).
- Unpinned `numpy` / `pandas` / `starlette` / `fastapi` in `requirements-scanner.txt` risk cross-architecture float drift between the Pi (`aarch64` container) and the Mac (`ScannerSyncClient` checks `numpy_match` against `/v1/status`).

## 2. Verification & Tests
- Apply patch with: `git apply docs/status/proposals/E-036.patch`
- Verify all lines in `requirements.txt` and `requirements-scanner.txt` have `==` exact version pins.
